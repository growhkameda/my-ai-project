# DezineMemo（ToDoアプリ）仕様書

## 概要
ユーザー登録・ログインにより個人のToDoを管理できるWebアプリケーション。ToDoの作成・編集・削除、カテゴリ別表示、完了済み表示、ページネーションを提供する。フロントはReact、バックエンドはPython、DBはPostgreSQLで構成する。
